5 個核心思考與日常工具

不是要否定過去，而是讓你看見：今天仍然可以重新選擇。

1. 離開「大腦的複製模式」

大腦會利用過去的經驗、創傷與家庭制約預測今天。當你發現自己重複舊模式，可先問：這是當下的選擇，還是過去為了安全與控制形成的反應？

2. 觀察身體的「輕與重」

面對一個選擇時，留意身體是開闊、放鬆，還是緊縮、沉重。它不是絕對的真偽判斷，而是一條協助你了解自己需要與界線的線索。

3. 放下不再適用的舊觀點

當焦慮或負面情緒重現，可以承認它，然後對自己說：「我願意放下並停止重新創造這個限制。」讓自己回到當下，再作選擇。

4. 每日解藥句

早晚慢慢說十次：「生命中的一切，都可以帶着輕鬆、愉快與光彩來到我身邊。」不必強迫自己相信，只需觀察說完之後身體有甚麼變化。

5. 做自己，不再為連結而倒退

你不必為了留在家人或朋友熟悉的位置，而把自己拉回沉重狀態。當你少一點批判，多一點自在與真實，你的存在已經在影響身邊的世界。

這些內容是自我覺察工具，不代替心理或醫療專業意見。
